# 부산 교과전형 안내 (2028학년도)

부산 4년제 대학 14곳의 학생부교과전형이 내신을 어떻게 계산하는지, 특히 **몇 과목을 성적에 넣는지**를 모은 사이트.
중하위권 학생이 모든 과목에 힘을 나누기보다 한두 과목에 집중하는 전략을 세우도록 돕는다.

- 사이트: https://busan-gyogwa.web.app
- 만든 사람: 동래고 김혜경

## 화면
- 홈 — 대학별 성적에 들어가는 과목 수(적은 순)
- 계산기 — 한 학기 등급을 넣으면 대학별로 들어가는 과목·빠지는 과목·평균
- 비교표 / 과목 선택 / 선발 비율 / 원문 자료 / 안내

## 자료 기준
각 대학 **2028학년도 대학입학전형 시행계획** 원문(2026-09-29 입학처에서 받음).
- 숫자는 `src/data/universities.js`에 있고, 전형마다 원문 인용(`count.quote`)과 쪽수(`sources`)를 달았다.
- 원문 파일은 `자료/시행계획_원문/`에 둔다(용량 때문에 저장소에는 올리지 않음).
- 부산외대·인제대는 입학처가 직접 받기를 막아 사본을 `public/plans/`로 사이트에 올렸다.
- 동아대 반영 과목 수만 2027 모집요강 값이다(2028 시행계획에 없음).
- 부산교대는 2027.3 부산대와 통합되어 2028 교과전형이 없어 뺐다.

## 명령
```bash
npm install
npm run dev -- --port 5180      # 개발 서버
npm run build                   # dist/ 생성
firebase deploy --only hosting:busan-gyogwa --project susi-3c093
```

## 구조
- `src/data/universities.js` 대학·전형 데이터
- `src/data/rules.js` 반영 과목 수 설명, 계산기 규칙(5학기 상위 N, 교과별 N, 필수 과목)
- `src/data/subjects.js` 2022 개정 교육과정 과목 목록
- `src/pages/` 화면들, `src/index.css` 스타일(라이트·다크)
